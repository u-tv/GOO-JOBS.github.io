Job Overview Coursera is seeking a Senior AI Specialist to own the technical design and delivery of complex AI applications for business and customer needs. You’ll turn ambiguous requirements into production-grade solutions, working across data exploration, experimentation, architecture, implementation, evaluation, and deployment. This is a hands-on senior IC role: you’ll lead architectural decisions independently, build critical components, and resolve difficult problems across models, agents, applications, and data. You’ll partner with Product Managers, Data Engineers, Software Engineers, LLMOps, and forward-deployed teams to deliver solutions within enterprise and customer environments. Your work will establish reusable approaches and technical standards that improve AI quality, reliability, security, and delivery across projects. About your skills: AI Systems Architecture — Design end-to-end applied AI solutions, combining models, retrieval, agentic workflows, and application services while balancing quality, scalability, security, and cost. AI Delivery & Reliability — Build production grade AI components and reliable data workflows, integrating enterprise data, models, and tools into tested, maintainable applications. Define how AI quality is measured and monitored, using evaluation frameworks, agent tracing Technical Leadership — Own complex technical decisions, lead design and code reviews, AI evals, and guide cross-functional teams from experimentation through validated production deployment. What you'll be doing Own AI solution architecture - Translate ambiguous requirements into robust system designs, service boundaries, data contracts, and implementation plans. Lead build v/s buy decisions and document trade-offs across model quality, latency, throughput, reliability, security, and cost. Architect RAG systems. Design retrieval-augmented generation pipelines using vector databases, sparse and dense retrieval, hybrid search, metadata filtering, and reranking. Define document parsing, chunking, embedding, and indexing strategies. Evaluate and fine-tune models . Determine when model adaptation is warranted over prompting or retrieval. Curate training and validation datasets, implement supervised fine-tuning and parameter-efficient techniques such as LoRA, and benchmark against baseline models for task accuracy, safety, latency, and cost. Develop AI services and data integrations. Build critical Python/TypeScript services, APIs, and asynchronous workflows. Partner with Data Engineering on ingestion and indexing pipelines, including normalization of customer data, schema validation, incremental updates, lineage, and recovery. Build enterprise agentic systems. Develop stateful workflows with task decomposition, planning, multi-step tool use, dynamic tool selection, structured outputs, memory management, and multi-agent orchestration where justified. Build tool and MCP integrations with validated inputs, scoped permissions, and human approval for sensitive actions. Evaluate retrieval and agent quality against defined accuracy and grounding metrics . Implement AI security, and governance controls. Implement defenses against prompt injection, sensitive-data leakage, unauthorized tool execution, and retrieval access violations. Contribute threat models, adversarial tests, and evidence for governance reviews. Translate centrally defined policies into application controls for identity, tenant isolation, data residency, retention, and auditability. Adapt solutions to enterprise environments. Work with Engineering and forward-deployed teams to implement cloud, hybrid, and customer-controlled deployments. AI evaluation and production observability. Define evaluation datasets and measure retrieval quality, groundedness, task completion, tool correctness, latency, and cost. Combine deterministic checks, calibrated LLM-as-judge, and human review. Partner with LLMOps on CI/CD release gates, prompt and model versioning, tracing, and safe rollouts and rollbacks. Own technical quality and system reliability. Set and enforce quality standards across the team, with accountability for code quality, maintainability, and production reliability. Lead architecture and code reviews, mentor AI Specialists, and drive root-cause analysis across model, retrieval, application, and data layers. Improve developer productivity through reusable libraries, reference architectures, tooling, and runbooks. Qualifications 6+ years in applied AI, machine learning, or software development, including architecture and production ownership of complex AI systems. Experience applying enterprise AI controls , including scoped tool authorization, tenant isolation, PII handling, prompt-injection defenses, audit logging, and human approval for sensitive actions. Experience designing enterprise semantic layers or context graphs that connect business entities, relationships, and definitions across systems. Strong experience with cloud deployments using GCP/AWS including serverless technologies, CI/CD pipelines using GitHub, Docker and Kubernetes and model platforms such as Vertex AI, Bedrock, etc. Familiarity with centralized LLM gateways such as LiteLLM, covering multi-provider routing, fallbacks, rate limits, token budgets, caching, and access policies. Production-grade development using Python, TypeScript, and SQL , with typed interfaces, APIs, asynchronous processing, and automated testing. Build enterprise agentic systems using LangGraph, Mastra, or equivalent frameworks , including planning, multi-agent orchestration, state and memory management, checkpointing, and failure recovery. Applied knowledge of LLM inference and context engineering , including structured outputs, embeddings, hybrid retrieval, reranking, and evaluation-driven model selection or fine-tuning. Practical work with Databricks, Spark, and Postgres , spanning analytical and transactional workloads, batch and real-time pipelines, and normalization of messy customer data. AI evaluation using Braintrust or equivalent , including golden datasets, custom scorers, regression testing, and calibrated LLM-as-judge to measure task success, tool correctness, safety, and cost. Worked on enterprise AI observability layers , including agent traces, model and tool spans, prompt versions, error attribution, latency, token usage, and cost tracking.
