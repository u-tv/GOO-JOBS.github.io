We are looking for a Senior Automation Engineer to design and scale intelligent automation across Okta’s Enterprise Technology ecosystem. This role will reduce manual operational work, improve developer productivity, and accelerate the software delivery lifecycle across platforms such as Salesforce, NetSuite, AEM, Boomi, identity systems, CI/CD platforms, and other enterprise applications. The engineer will build reliable automation services, reusable integration patterns, and AI-assisted developer agents that understand source code, metadata, configuration, tickets, documentation, deployment history, and operational context. These solutions will automate release activities, identify deployment risks, reduce merge-conflict resolution effort, improve environment management, and enable safe self-service operations. The role requires a combination of software engineering, enterprise application expertise, API and integration development, CI/CD automation, security engineering, and practical experience applying AI to developer and operational workflows. The ideal candidate is comfortable moving between platform-specific technologies and building scalable, secure, platform-agnostic automation frameworks. What you'll be doing Intelligent Automation and Developer Productivity Build AI-assisted developer agents and automation services that reduce repetitive engineering and operational work. Use contextual information from Git repositories, metadata, tickets, documentation, deployment logs, and platform APIs to make automation more accurate and useful. Automate release planning, validation, dependency analysis, testing, deployment coordination, post-release verification, and rollback activities. Build tools that detect potential merge conflicts, explain their impact, and recommend or execute safe resolutions with appropriate human approval. Develop agents that assist with code and metadata analysis, documentation, test generation, troubleshooting, incident response, and operational runbooks. Establish metrics to measure productivity gains, manual effort reduction, deployment quality, and automation adoption. Cross-Platform Enterprise Automation Design and implement automation across Salesforce, NetSuite, AEM, Boomi, Okta, GitHub, CI/CD systems, ticketing platforms, and other ET applications. Build reusable APIs, connectors, scripts, workflows, and event-driven services. Create platform-agnostic automation patterns for authentication, authorization, retries, error handling, logging, monitoring, and auditability. Develop self-service capabilities that allow teams to safely perform approved tasks without direct manual intervention. Monitor, troubleshoot, and improve end-to-end workflows spanning multiple enterprise applications. Salesforce Platform Engineering and Security Design and optimize Salesforce Flows, declarative automation, Apex utilities, and platform integrations. Implement Profiles, Permission Sets, Permission Set Groups, FLS, Sharing Rules, OWDs, Shield, Event Monitoring, and related security controls. Build data masking and lower-environment protection processes for sensitive information. Debug and refactor platform automation to improve reliability, performance, and maintainability. Review third-party packages, Connected Apps, OAuth configurations, and API access in partnership with Security and Privacy teams. Release, CI/CD, and Environment Automation Eliminate manual deployment and environment-management steps through automation. Build CI/CD integrations for metadata validation, testing, deployment, approvals, and rollback. Automate sandbox refreshes, data masking, metadata synchronization, configuration updates, and post-refresh activities. Maintain automation code and configuration in GitHub using appropriate branching, testing, review, and release practices. Partner with Release Engineering and DevSecOps teams to standardize deployment and operational patterns Automation Security, Governance, and Reliability Implement least-privilege access for service accounts, agents, integrations, and automation workflows. Apply guardrails and human approval controls to high-risk actions. Protect sensitive data used by automation and AI systems. Maintain comprehensive execution logs, audit trails, monitoring, and alerting. Design for reliability through testing, idempotency, retries, failure recovery, and rollback.
