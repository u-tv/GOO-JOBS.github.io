Bitovi: Backend / Platform Developer Consultant (Temporal & Kubernetes)

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: United States URL: https://bitovi.com JOIN OUR TEAM! Bitovi is looking for a Backend / Platform Developer Consultant to join us as we transform technology delivery. We build and operate durable, distributed systems for enterprise clients — heavy on Java Services, Temporal for workflow orchestration, Kafka for event streaming, and Kubernetes-native platform engineering on AWS to run it all reliably. If you want to build exceptional systems, take orchestration, systems engineering, and infrastructure seriously, and have ideas for making delivery more collaborative, validation-driven, and swift, we want to work with you! Compensation: $120,000 to $190,000 annually, depending on experience, plus annual bonus opportunity. PLEASE NOTE: At this time, we are only considering candidates located in and authorized to work in the United States. WHO YOU ARE You're experienced building and running applications at the enterprise level, and you're comfortable owning both the code and the infrastructure it runs on. You think like a systems engineer — reasoning about the whole platform, from JVM services and event streams to the clusters and cloud infrastructure underneath them. You thrive when given opportunities to deliver real-world platforms as an integral team member, including large-scale migrations, and you have the expertise to interface and communicate confidently with stakeholders.
