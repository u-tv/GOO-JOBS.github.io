Proxify AB: Senior QA Automation Engineer

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: Sweden URL: http://career.proxify.io The Role: We are looking for a Senior QA Automation Engineer to join one of our high-growth client teams as the primary architect of their quality assurance strategy. In this role, you will move beyond manual validation to build robust, scalable automation frameworks that ensure software reliability at high velocity. You will be responsible for the entire testing lifecycle—from defining test strategies and selecting the right tools to integrating automated suites into modern CI/CD pipelines. This is a role for a 'Developer in Test' who is passionate about building invisible safety nets that empower development teams to ship code with total confidence. What we are looking for: 5+ years of experience in test automation, with deep expertise in modern frameworks like Playwright, Cypress, or Selenium. Strong ability to write clean, maintainable test code in TypeScript/JavaScript, Python, or Java. Proven track record of building and scaling automation frameworks from scratch (Page Object Model, Screenplay Pattern, etc.). Extensive experience testing RESTful and GraphQL APIs using tools like Postman, SuperTest, or RestAssured. Hands-on experience integrating automated tests into pipelines using GitHub Actions, GitLab CI, or Jenkins. Experience with mobile automation using Appium or Maestro is a significant advantage. Familiarity with performance testing tools like k6 or JMeter to identify system bottlenecks. Located in CET timezone (+/- 3 hours), we are unable to consider applications from candidates in other time zones. Nice-to-Have: Knowledge of Docker for containerized testing environments. Experience with Visual Regression testing tools (Percy, Applitools). Familiarity with Cloud Testing platforms (BrowserStack, Sauce Labs, AWS Device Farm). Background in Security Testing (OWASP principles). Responsibilities: Define the overall automation roadmap and select the appropriate tools to match the client's technical stack. Write, maintain, and optimize complex end-to-end (E2E) integration and regression test suites. Partner with Developers and Product Managers to define 'Definition of Done' and ensure testability is considered during the design phase. Identify, document, and track software defects, working closely with the dev team to ensure rapid resolution. Act as the 'Quality Evangelist' within the team, conducting code reviews for test scripts and sharing best practices in automated testing. What we offer: Get paid, not played No more unreliable clients. Enjoy on-time monthly payments with flexible withdrawal options.
