The Developer Infrastructure org is the engine behind Robinhood's entire engineering organization — a collection of tightly integrated teams whose collective mission is to make every engineer at Robinhood faster, more reliable, and exponentially more productive. The org spans four major teams: DevX (Developer Experience), TestX (Test Infrastructure), Backend Platform, and Mobile Platform. DevX owns Robinhood's monorepo and Bazel-based build infrastructure — the critical layer between a developer writing code and that code being ready to ship — along with the company's full CI/CD pipeline and remote build execution cluster. TestX owns the infrastructure behind Robinhood's entire test experience: the integration test environments, and personal development environments that serve as miniature simulations of the full Robinhood system, giving engineers a safe, isolated space to test their code end-to-end before it ever touches production. Backend Platform and Mobile Platform own the core language runtimes, libraries, IDEs, and developer toolchains across Python, Go, TypeScript, Swift, and Android. Together, these teams share a single north star: leveraging AI and agentic systems to fundamentally transform Robinhood's software development lifecycle — making every engineer dramatically more productive and the entire org a force multiplier for the business. As the Senior Staff Software Engineer, Developer Infrastructure , you are the technical driver of this entire org — the Uber Tech Lead unifying DevX, TestX, Backend Platform, and Mobile Platform under one cohesive technical vision. Your primary focus will be DevX, owning the technical direction of Robinhood's most critical build and developer infrastructure. But your influence stretches far wider: you will be a driving force in weaving AI and agentic development deeply into every layer of the software development lifecycle — from intelligent code review and automated build pipelines to agentic coding systems that multiply what each engineer can ship. This is a rare opportunity to shape not just how Robinhood builds software today, but what engineering velocity looks like for the entire industry!
