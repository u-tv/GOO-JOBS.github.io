Position Description We are seeking an experienced Senior Software Engineer to join the Advanced Integration Builder team within Okta. This team builds and maintains the backend services, provisioning frameworks, authentication connectors, and next-generation Entitlement Management engines that let Okta customers secure, integrate, and govern access to thousands of third-party enterprise applications — from modern cloud platforms (Microsoft Office 365, Workday, Salesforce, AWS, ServiceNow) and AI agentic systems to legacy on-prem systems. As a Senior Engineer, you will own the technical design and implementation of integration components end-to-end: REST/SOAP API clients, OAuth2/SAML authentication flows, user and group provisioning/sync jobs, and the retry and rate-limiting logic required to operate reliably against dozens of idiosyncratic third-party vendor APIs at scale. This is a backend-intensive role — the large majority of your time will be spent in Java/Spring Boot services — but you'll also need decent frontend experience in React and JSP to build and extend the screens that surface integration configuration to customers Job Duties and Responsibilities - Feature Execution: Drive technical design and implementation of integration features — new app connectors, provisioning/sync capabilities, authentication flows — primarily in backend Java services, extending into React/JSP configuration screens. - Build and maintain REST/SOAP API clients, OAuth2/SAML authentication handlers , and vendor-specific exception/error-mapping layers for third-party SaaS and enterprise applications. - Implement and extend user/group provisioning adapters built on shared contracts and scheduled sync/import jobs that keep identity data consistent between Okta and external systems. - Resilience at Scale: Apply retry/backoff, rate-limiting, and pagination strategies to handle vendor API quirks, throttling, and intermittent failures gracefully across the dozens of concurrently supported integrations. - Security & Compliance: Ensure credential/secret handling, token exchange, and audit logging for provisioning operations meet Okta's security and compliance standards. - Product & Cross-Functional Alignment: Partner with PMs, support, and technical leads to prioritize new app integrations, resolve customer-reported connectivity issues, and participate in technical interviews/recruiting. - Operational Excellence: Participate in on-call rotations, troubleshoot production issues in integration pipelines, drive root-cause analyses, and improve observability/alerting for sync and provisioning jobs. - Code Quality & Technical Standards: Participate in code reviews, write thorough unit and functional tests, and maintain clear technical documentation. Required Knowledge, Skills, and Abilities - Experience: 5+ years of hands-on experience building and operating reliable, production-grade backend services. - Backend Expertise: Strong proficiency in Java and Spring Boot; comfortable owning services end-to-end from design through production support. - Distributed Systems: Experience with asynchronous job processing, scheduled/batch sync jobs, and event-driven patterns. - Data Management: Proficiency with relational databases (MySQL) and caching layers (Redis or similar). - Resilient Systems Design: Practical experience with retry/backoff strategies, rate-limiting, and handling pagination/throttling quirks from third-party APIs. - API Design: Experience designing and consuming RESTful APIs, including clients for third-party vendor systems with varying levels of API quality and documentation. - Problem Solving & Ownership: Ability to break down ambiguous integration requirements and independently drive a feature from design to production. - Decent Frontend Experience: While the role is backend-dominant, you should be comfortable building and modifying UI in React and JSP — well enough to independently deliver the frontend without relying on a dedicated frontend engineer. Nice to Haves - Experience with identity/IAM standards (SCIM, SAML, OAuth, OIDC) or directory services (AD, LDAP). -Integration & Auth Protocols: Working knowledge of REST/SOAP API integration patterns and authentication standards such as OAuth2, SAML, or WS-Federation. - Exposure to legacy protocol support (SOAP-based provisioning services) alongside modern REST/OAuth integrations. - Familiarity with multi-tenant SaaS architectures or specialized compliance environments (e.g., FedRAMP/GCC-High). - Experience with message brokers/queueing systems (Kafka) for asynchronous processing. - Exposure to HTTP mocking/test-server frameworks (e.g., WireMock or equivalent internal mock-server tooling) for API-level testing.
