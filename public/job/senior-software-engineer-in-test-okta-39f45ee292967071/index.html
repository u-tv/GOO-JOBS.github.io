Senior Software Engineer in Test - Essential Security We seek an experienced Senior Software Engineer in Test to join our Essential Security engineering team. This team owns Okta's core threat detection and protection capabilities, including Threat Insight, the Orbit detection engine, KDA data pipelines, breached-credential detection (SpyCloud), Bot Protection, and Adaptive OIE. You'll ensure these capabilities ship with zero-debt quality across every new cell and platform upgrade. Job Duties and Responsibilities: - Review requirements and design specs to develop test plans and test cases for Threat Insight, Orbit, and KDA data pipeline features - Automate API tests, end-to-end tests, and reliability/scale tests for Kafka to KDA to DynamoDB detection pipelines - Own QA support for platform-wide initiatives (e.g., Monolith Spring upgrades) affecting Essential Security surfaces - Validate new cell rollouts across OIE orgs: Orbit enforcement, Threat Insight detection, and data-lake IP allowlists - Automate all critical features (Bot Protection, breached-credential detection, IPv6) to maintain zero-debt cadence - Review application code, identify bugs and other areas of weakness, architect tools for future coverage - Own weekly release sign-off and respond to production issues/red alerts during on-call rotation - Release features with solid quality - Be a strong customer advocate with a strong quality DNA Requirements: - Minimum of a Bachelor's degree in software engineering (or related) - 4+ years of QE/SDET experience, preferably in an enterprise SaaS company or any product-based company - Experience in quality engineering for enterprise-level software - Experience in Java or Python or TypeScript - Familiarity with automation tools like Playwright, Selenium, TestCafe, API (Rest Assured, Karate, etc.), Postman, Jmeter, Splunk, Runscope, and AWS toolset - Experience testing streaming or event-driven data pipelines (Kafka, DynamoDB, or similar) - Expertise in test planning and cross-team collaborative efforts - Experience with continuous integration/continuous deployment (CI/CD) practices -
