About the job This position is needed to help build, operate, and maintain the global corporate network infrastructure, VPN, ZTNA, and connectivity to our cloud-based systems. As part of the Identity and Network Trust team, you will monitor network performance to proactively respond to incidents. You will need to possess the technical knowledge to troubleshoot and perform root cause analysis for escalated connectivity issues. You also will collaborate with the security team and other engineering teams to develop a secured global network infrastructure. Responsibilities Build, operate and support the global Twilio IT network infrastructure. Keep track of network assets, including network hardware and software. Monitor the network performance, availability, utilization, throughput and latency, providing measurable metrics to the IT leadership team. Work closely with stakeholder teams to determine current and future network needs. Prioritize projects and work based on business priorities using the Scale Agile Framework (SAFe). Develop methods and tools to be used to test and implement new LAN/WAN systems. Analyze the current network structure and collaborate on how to make the network more efficient, scalable and sustainable. Formulate strategies to maintain and upgrade network systems efficiently. Respond to incidents, engage in network troubleshooting activities to determine root cause and resolve network issues. Create and maintain documentation for network design, IT network standards and process. *Required: 7+ years of experience with building campus and/or data center network infrastructure, AWS cloud services and networking 5+ years of experience with Cisco LAN/WAN/Wifi and Palo Alto Networks firewalls 3+ years experience with AWS cloud services and networking Advanced knowledge of IEEE 802 standards and core IETF networking protocols including 802.11 suite, TCP/IP, DNS, DHCP, routing and switching protocols Hands on knowledge of network monitoring Knowledge of network security to implement security policy for compliance Proficient skill in WIndows, Mac, Linux client networking Experience in troubleshooting network problems at different OSI model layer University degree in computer science or equivalent experience Excellent written and verbal communication skills Desired: Cisco CCNA/CCNP Certification AWS certification Zscaler Zero Trust Systems experience and/or certifications Scripting language with API automation Experience with infrastructure as code (IaC) using Terraform Knowledge of ITIL framework and its application in a network environment Project management skills Location This role will be Remote and based in India (Karnataka, Tamil Nadu, Telangana, Maharashtra, Delhi) Travel We prioritize connection and opportunities to build relationships with our customers and each other.
