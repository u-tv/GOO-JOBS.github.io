Staff Software Engineer, Code Forge

🏢 stripe 📍 San Francisco, Seattle, US-Remote 💼 Full-time 💰 Not disclosed

Job Description

Who we are About Stripe Stripe is a financial infrastructure platform for businesses. Millions of companies—from the world’s largest enterprises to the most ambitious startups—use Stripe to accept payments, grow their revenue, and accelerate new business opportunities. Our mission is to increase the GDP of the internet, and we have a staggering amount of work ahead. That means you have an unprecedented opportunity to put the global economy within everyone’s reach while doing the most important work of your career. About the team The Developer Productivity organization works to make Stripe the most productive place of an engineer’s career. The Code Review team builds the tools and processes that help Stripe engineers review and ship code safely and efficiently. We treat engineers’ attention as a valuable resource, building tools that help them understand changes and focus on the decisions that need human judgment. Our goal is to build an AI review agent that outperforms human review at preventing problems after changes merge, while helping developers move quickly. We are also moving code review from GitHub to Orbit Diffs, Stripe’s own review interface, and enabling Stripe’s migration from legacy source control infrastructure to new systems, including infrastructure built at Stripe. What you’ll do As a Staff Software Engineer, you will take ownership of problems across the code review domain, set technical direction, and build alignment across Stripe. You will combine technical leadership with hands-on engineering to build the systems that determine which changes can be approved by agents and when human judgment is needed. Your decisions will influence both the pace and safety of changes across Stripe. You will work across user interfaces, backend services, source control integrations, and agent harnesses. Our team works primarily in Go, Ruby, and TypeScript, and you will use the technologies each problem requires. As AI capabilities evolve, you will experiment with new approaches and turn them into reliable, maintainable tools for developers. Responsibilities Set technical direction for code review, build alignment across Stripe, and mentor engineers as you lead complex projects from problem definition through delivery and adoption Build and improve agent harnesses that enable review agents to exercise judgment and safely approve pull requests Develop evaluations that compare agent and human review decisions, assess the safety of merged changes and the impact on developer velocity, and guide improvements to approval decisions Evaluate and apply advances in AI and agent orchestration to accelerate engineering delivery across Stripe while maintaining review quality, maintainability, reliability, and change safety Build and maintain Orbit Diffs and the surrounding code review tools, helping engineers understand changes and focus their attention where their judgment is most valuable Improve code ownership, intelligent reviewer assignment, stacked pull request workflows, and controls for change management Support Stripe’s migration to new source control infrastructure by adapting code review workflows and integrations Partner with security, compliance, infrastructure, reliability, and language and runtime teams to improve how software changes are evaluated and approved across Stripe Who you are We’re looking for someone who meets the minimum requirements to be considered for the role. If you meet these requirements, you are encouraged to apply. The preferred qualifications are a bonus, not a requirement. Minimum requirements BS or MS in Computer Science or a related field 10+ years of professional software engineering experience, including designing, building, and operating reliable production software across languages and system boundaries Experience owning a technical domain, setting technical direction, and leading complex projects from ambiguous problems through delivery Experience using data and user feedback to evaluate quality, understand user needs, and guide engineering decisions Experience building alignment across teams, explaining technical tradeoffs, and adapting your approach as technologies evolve Preferred qualifications Experience building agent harnesses, orchestrating agents, or designing evaluations for agent behavior Experience building developer productivity tools, especially code review or related workflows Experience with software change management and compliance, including designing, implementing, or maintaining controls
