API Support Engineer

🏢 asana 📍 Warsaw 💼 Full-time 💰 Not disclosed

Job Description

As a Developer Support Engineer, you’ll be a trusted technical partner for developers and customers integrating with the Asana platform. You’ll focus on API-related troubleshooting, developer workflows, and integration challenges - helping customers build reliably and confidently on top of our APIs. This is a hands-on role requiring basic programming skills, strong analytical skills, API debugging expertise, centered on delivering high-quality, developer-first support, combining technical depth with clear, empathetic communication. In this role, you’ll work closely with customers to understand their use cases, diagnose complex technical issues, and advocate for improvements to our APIs and platform capabilities. You’ll collaborate cross-functionally with Engineering, Product, and Developer Relations to drive scalable solutions, share developer insights, and improve the overall integration experience. You’ll thrive here if you’re technically curious, detail-oriented, and passionate about helping developers succeed through thoughtful, durable solutions—not just quick fixes. This role is based in our Warsaw office with an office-centric hybrid schedule. Along with most Asanas, you’ll work from this office in person on Mondays, Tuesdays, and Thursdays. Most Asanas have the option to work from home on Wednesdays and Fridays. If you're interviewing for this role, your Talent Acquisition Partner will share more about the in-office requirements. You will: Provide technical support to customers, including debugging, troubleshooting and resolving API-related issues. Given the complexity and breadth of Asana's use across many industries, this is not a typical &quot;question and answer&quot; support role. Triage and escalate API-related bugs and critical issues to R&D teams. Support developers through email, our community forum, and live chat, ensuring they can successfully build on our platform. Monitor internal Slack channels for urgent API support requests. Collaborate with R&D teams to understand our API and influence improvements based on customer feedback. Assist with API releases by communicating changelog updates and deprecation notices. Review and approve third-party app integrations based on security and compliance guidelines. Update developer documentation to clarify API usage and best practices. Act as a liaison between API teams and Customer Support to ensure smooth communication about upcoming releases and changes. Provide customer communication support during incidents involving API, webhooks, or event streams. About You: 3+ years of experience in technical support, developer support, application development or a related role. Experience developing or integrating applications using APIs (including personal projects). Strong written and verbal communication skills in English, with the ability to explain technical concepts to both technical and non-technical audiences. Strong understanding of REST API fundamentals (HTTP methods, JSON, pagination, query parameters, request bodies/responses). Ability to write and debug scripts in JavaScript or Python to interact with APIs. Excellent troubleshooting and debugging skills, with the ability to interpret error messages and resolve API-related issues. Experience working cross-functionally with engineering, product, and support teams. Comfortable with and has experience working in fast-paced, agile, and ambiguous environments while working in a consultative manner with customers Nice to Have Understanding of OAuth concepts and authentication protocols. Basic Git proficiency. Familiarity with webhooks and event-driven architectures. Experience with command-line tools and basic Linux/Unix navigation. Prior experience in developer relations, technical writing, or API advocacy. Experience working with the Asana API or similar productivity tool APIs. Experience with PowerBI and/or Tableau custom connectors Public speaking, blogging, or content creation about technical topics.
