Product Manager, Software Factory

🏢 vercel 📍 Hybrid - San Francisco 💼 Full-time 💰 Not disclosed

Job Description

About Vercel: Vercel is the agentic infrastructure company, freeing people and agents to ship what's next. For more than a decade we've helped builders move from idea to production with speed, security, and exceptional developer experience. Now we're scaling our products for both agents and people to ship and run software, built in the open and trusted by OpenAI, PayPal, Ramp, Supreme, and millions of developers worldwide. About the role As a Product Manager, Software Factory, you’ll own a new product area that puts AI agents on every stage of the development loop: triaging an issue, planning it, writing the code, and checking the result, while keeping people on the judgment calls. Human time and attention are now the bottleneck, and the opportunity is to automate continuous software maintenance and improvement. You’ll define how agents help fix bugs, implement features, improve performance, mitigate security issues, improve code quality, and increase test coverage. This is a hybrid role based in San Francisco, in the office on Monday, Tuesday, and Friday. What you'll do Own the product vision, strategy, and multi-year roadmap for Software Factory Define the workflow model: how work moves through classification, analysis, implementation, and review, and where the handoff back to a person belongs Own the trust and quality bar (evals, verification, retry behavior, and what the factory may touch without human approval) and shape the memory and context model that lets a factory build up knowledge of a repository over time Define how factories integrate with where engineering work already lives, including GitHub and Linear, and with agent harnesses such as Codex and Claude Code, and define new dedicated surfaces for interacting with factory agents Work directly with design partners and Enterprise customers adopting factories against their own codebases What you need 8+ years of product management experience, including developer tooling products (ideally CI/CD, code review, developer productivity, or AI coding tools) Used coding agents hands-on, and can describe where they succeed and where they fail today Technical depth in agent orchestration, evals, context management, and sandboxed execution Owned a platform area that other product teams build on, and set technical direction others adopted Worked on products with probabilistic output, defining acceptance bars and measuring quality over time Worked directly with design partners or Enterprise customers on adopting new engineering workflows Bonus if you Have worked on multi-agent systems or agent orchestrators Have worked on products adopted bottom-up by individual developers before spreading to teams Have run or operated a large open-source project Compensation & Benefits: Competitive compensation package, including equity. Inclusive Healthcare Package. Learn and Grow - we provide mentorship and send you to events that help you build your network and skills. Flexible Time Off.
