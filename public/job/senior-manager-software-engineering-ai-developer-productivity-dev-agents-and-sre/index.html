About the role AI is changing how our R&D organization builds and runs software. This is a new role: one leader for Samsara's AI bets across the software development lifecycle. You'll own two efforts that started and whatever comes next. Dev Agents builds in-house and integrates vendors such as Claude and Codex. That includes an Agent Gateway that serves internal MCPs, managed access to skills, and cloud runners that fan work out to cloud agents. SRE AI is an agent that does the first-line work of an on-call engineer. It already runs on real incidents in production: it writes a root cause analysis, escalates severity when it has proof, and can roll back the deployment it identified as the cause. This is a new role. You'll lead a team of five to 10 senior engineers, from Senior to Staff. You'll work directly with every R&D leader and with the developers who use what you build.
