Toptal: AI/ML Engineer for an AI-Driven E-Commerce Platform

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: We are seeking an AI Engineer to develop AI-first applications and integrate custom models and infrastructure into an existing e-commerce platform. The role focuses on building agent-led product experiences, including internal automation, dynamic site customization, and customer-facing conversational commerce workflows. General information This engagement supports an e-commerce startup building a platform around conversational design and intelligent automation. The current objective is to extend the existing product with AI-native capabilities while building on top of the current backend and application stack. The work includes three core initiative areas: an internal AI employee for operational tasks, a fluid site customizer, and a customer-facing commerce agent designed to support one-prompt checkout experiences. The role will involve model integration, infrastructure setup, and product-facing implementation across both backend and UI surfaces. Tasks and Deliverables - Develop AI-first applications for an existing e-commerce platform. - Architect and implement autonomous e-commerce AI agents using open-source and proprietary foundation models. - Establish GPU infrastructure and data pipelines for model fine-tuning and deployment. - Integrate AI workflows with the existing stack, including MongoDB, Node.js, Express, React, and third-party APIs. - Build conversational UI components and backend logic for one-prompt checkouts and dynamic site customization. Required Experience - Strong expertise in AI/ML engineering and LLM integration. - Hands-on experience fine-tuning open-source models such as Llama or Mistral. - Experience building autonomous agents and conversational AI workflows. - Solid background in GPU infrastructure setup and optimization for training or inference. - Full-stack proficiency with MongoDB, Express, React, and Node.js. - Experience integrating REST APIs into production applications. Nice to have: - Familiarity with Stripe, Twilio, or OpenAI API integrations. To apply: https://weworkremotely.com/remote-jobs/toptal-ai-ml-engineer-for-an-ai-driven-e-commerce-platform
