Locations: Austin, Lisbon, San Francisco, NYC, or London About the Role Search is being rebuilt around AI. People increasingly get answers from AI instead of a list of links, agents run dozens of searches to answer a single question, and more than half of the traffic reaching sites on Cloudflare is now automated . Search is shifting from a destination to a utility, and Cloudflare is building the search layer for this agentic Internet. Agentic Search at Cloudflare gives agents everything they need to find information, whether it lives in a customer’s own data or on the open web. It spans two products: AI Search for internal data, and Web Search API for the open web. AI Search (internal data), now generally available , is the search primitive for applications and agents . It is a fully managed indexing and retrieval pipeline built on Workers AI , Vectorize , R2 , and Browser Run . Developers connect a website or R2 bucket, or upload their own files, and query them with natural language through a Workers binding, REST API, or MCP server. Under the hood: continuous indexing, hybrid vector and keyword retrieval, reranking, metadata filtering, native multimodal (image) embeddings, and OCR for scanned documents. We use it to power search on our own blog and developer docs. Web Search API (external data), now in open beta , gives agents real-time web context with a single API call. It runs on AI Gateway , so every search gets the same logging, analytics, billing, and access controls as model inference. Developers can choose from multiple search providers and always get results back in one normalized format. Your mission in this role is to make Cloudflare the default place developers and agents go to search, across both their own data and the open web, and eventually in a single call. You’ll also help build a search ecosystem that works for AI companies, site owners, and creators alike. What You’ll Do Talk directly with developers, AI companies, publishers, and customers every day. Own the strategy, roadmap, and execution for Agentic Search (AI Search and Web Search API), from ingestion and indexing through retrieval, ranking, and answer generation. Define and measure what “good search” means, including relevance, freshness, latency, and cost, and build the evals that improve it with every release. Scale AI Search for the workloads that matter most, like multi-tenant platforms, enterprise agents, and website search, with support for billions of documents, rich media, and built-in observability. Take Web Search API and shape what comes next: provider partnerships, search and page extraction in one call, blending web and private data, Own pricing and packaging, and make our products first-class for agents through MCP, agent-friendly APIs, and templates like NLWeb . Partner with engineering, ML, and product teams across Workers AI , Vectorize , AI Gateway , Browser Run , and AI Crawl Control , as well as Marketing, DevRel, BD, Sales, and Support. Represent Cloudflare at conferences, community events, and customer and partner meetings.
