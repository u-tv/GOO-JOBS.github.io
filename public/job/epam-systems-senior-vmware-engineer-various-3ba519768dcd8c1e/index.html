EPAM Systems: Senior VMware Engineer

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: Armenia, Georgia, Kazakhstan, Kyrgyzstan, Uzbekistan URL: http://epam.com We are looking for a Senior VMware Engineer to join our team supporting the delivery of a Unified Automation Platform for a large enterprise client. Within this role, you will develop and maintain VMware automation modules as part of an Internal Developer Platform (IDP) that standardizes project delivery, consolidates development resources, and ensures consistent provisioning across Azure and on-premises VMware environments. Your work will involve a modern toolchain built on Terraform/OpenTofu and Ansible, leveraging AI-assisted development with GitHub Copilot as a standard engineering practice. Responsibilities Develop and maintain Terraform/OpenTofu modules for vSphere VM provisioning, placement/resource-pool configuration, and cloud-init/cloudbase-init integration, following designs defined by the VMware Architect Create and run Ansible playbooks for post-provisioning configuration handoff on VMware-provisioned VMs Provide VMware DRS (affinity/anti-affinity rules, resource pools) and vSAN (storage policy) modules Assist with SRM (protection groups, recovery plans) and HCX (site pairing, network extension) module builds and test-cycle execution, including paired-site and failover testing Collaborate with the Network Architect on NSX-T segment and DFW rule implementation for VMware workloads Diagnose and resolve production issues across VMware automation modules during Implementation and Adoption phases Participate in module testing and documentation per the platform's Infrastructure as Code Engine standards Requirements 3+ years of hands-on experience building and operating VMware automation Expertise in vSphere, DRS, and vSAN via Terraform/OpenTofu and Ansible Background in VMware test cycles, including paired-site and failover testing approaches for HCX/SRM Knowledge of NSX-T network segmentation and distributed firewall (DFW) concepts sufficient to collaborate with the Network Architect Skills in Windows guest customization (cloudbase-init) and Linux cloud-init patterns Proficiency as a combined Terraform (IaC) and Ansible (CaC) developer Capability to work AI-assisted using GitHub Copilot as standard practice Strong command of written and spoken English (B2+ level) Nice to have Background in integrating VMware provisioning workflows with golden-image pipelines Knowledge of Microsoft Azure To apply: https://weworkremotely.com/remote-jobs/epam-systems-senior-vmware-engineer
