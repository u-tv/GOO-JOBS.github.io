Toptal: Power Platform Solutions Architect for Global Pharmaceutical Company

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: We are looking for a Power Platform Solutions Architect for a global company. Their goal is to assess and modernize an existing Power Platform solution, define the target architecture, and lead the technical design of a scalable and secure implementation. Required Skills: Deep hands-on experience with Microsoft Power Platform, including Power Apps (canvas and model-driven), Power Automate, Dataverse, Power Pages, and Power BI Strong experience designing Dataverse schemas and security roles Azure architecture experience with API Management, Azure Functions, Key Vault, Entra ID/SSO, and Azure Monitor/Application Insights Experience designing enterprise integration architectures, including integrations where counterpart APIs or contracts are uncertain, changing, or being migrated Experience integrating enterprise applications with ERP systems Experience designing identity and access models for licensed and unlicensed user audiences Strong understanding of Microsoft Power Platform licensing models, including per-user Dataverse licensing and capacity/session-based Power Pages licensing Experience evaluating existing solutions and defining modernization, remediation, or rebuild strategies Optional Skills (not mandatory): SAP integration experience Deliverables Lead the technical assessment of the existing Power Apps application, Power Automate flows, data layer, Power BI reporting, and four integration touchpoints Support the Regulatory data-profiling spike and incorporate findings into the target solution architecture Define and evaluate costed patch and rebuild options and support the final technical recommendation Produce a detailed and staffed Phase 2 implementation plan Design the consolidated Dataverse entity model and define workflow and business-logic architecture Define the target integration architecture across the four integration touchpoints Configure the Entra ID access model for licensed and unlicensed audiences Configure the shared Azure API Management, Key Vault, and monitoring architecture supporting the integrations Produce the technical handover documentation for the implemented solution General Information Location: USA or Canada only. Overlap: 6hs with the East Coast time zone, USATT Commitment: Approximately 30 hours per week during Phase 1 and 10 hours per week during Phase 2.
