The Platform Infrastructure, Control Team The Auth0 platform secures more than 100 million logins each day for customers all around the world - and we're growing fast! The Platform Control team enables Auth0 engineers to move faster by giving them tools to easily deploy and manage their services on AWS and Azure. This is a role with a huge impact. You will get to work with engineers throughout the organization and what you build will be a foundational piece of the infrastructure that allows Auth0 to scale for years to come. Software Engineer II, Platform Infrastructure - Control We are looking for an Engineer who is passionate about building robust orchestration systems, idempotent APIs, and high-quality developer tooling. Because we build the &quot;brain&quot; of the platform - handling everything from environment provisioning to emergency rollbacks, the ideal candidate is someone who is obsessed with system state consistency and creating a seamless, self-service experience for other engineers. What you’ll be doing Help build, maintain, and scale the Control Server, API, and CLI tools that manage the lifecycle of our environments, from provisioning to decommissioning. Contribute to backend logic powering automated rollbacks, hotfixes, and release patching to keep deployments safe and predictable. Enhance automated provisioners that enable product teams to self-serve high-fidelity test environments without friction. Implement and maintain event publishing pipelines to broadcast environment state changes reliably across platform services. Improve the developer experience by contributing to well-documented, intuitive CLI and API interfaces with actionable error messaging. Collaborate with Product, Security, and Quality Engineering teams to execute complex lifecycle workflows while adhering to platform standards. Participate in the team’s goalie rotation to support build and production operations when issues arise. What you’ll bring to the role Have 3+ years of software development experience, with a focus on building APIs, CLI tools, or backend services. Have a solid understanding of backend and distributed systems fundamentals (e.g., RESTful APIs, state management, basic idempotency, and asynchronous workflows). Have hands-on experience with Go (or Rust/C++/Java) and a pragmatic approach to using AI coding tools to explore new patterns, write clean code, and speed up day-to-day execution. Have practical experience provisioning or managing cloud infrastructure (AWS or Azure) programmatically or via Infrastructure as Code (Terraform, Pulumi). Have foundational knowledge of identity and access concepts (e.g., IAM, OAuth2, OIDC). Care deeply about developer experience, understand why clear CLI outputs, fast auth flows, and good documentation matter. Write reliable, well-tested code that anticipates common failure modes, network timeouts, and edge cases. Work well incrementally, seeking feedback early and iterating on technical solutions with senior team members. And extra credit if you have experience in any of the following! Working knowledge of PostgreSQL or other relational databases for managing application state. Exposure to Kubernetes internals (custom controllers/operators) or Terraform provider development.
