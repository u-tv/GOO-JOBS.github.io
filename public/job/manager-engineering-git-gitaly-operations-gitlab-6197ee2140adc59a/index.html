Fortune and Fortune Media IP Limited are not affiliated with, and do not endorse products or services of GitLab. An overview of this role This role is not a typical infrastructure operations role. As Manager, Engineering, Git & Gitaly Operations, you'll lead the team responsible for the infrastructure layer underneath Git at GitLab: the open source Git project itself, Gitaly, GitLab's Git storage and remote procedure call layer, and the services that make Git perform at enterprise scale. Git and Gitaly are core to GitLab. If they go sideways in production, they affect everything downstream, including continuous integration, code review, and deployments. This role starts with genuine subject matter expertise in Git technologies and extends to reliable operation across GitLab's deployment models: Self-Managed, GitLab Dedicated, and SaaS. You'll build and develop a team with deep platform expertise and strong operational judgment. You'll partner across engineering groups to shape how Git and Gitaly operations evolve as the platform grows. What you’ll do Build and lead a team with deep platform expertise in Git and Gitaly, hiring and developing engineers who can operate this infrastructure layer with strong operational judgment. Own production reliability for Git and Gitaly across GitLab's full deployment footprint. Drive incident management, root cause investigation, and postmortems with the technical depth to distinguish a Git internals problem from a generic infrastructure problem. Design and operate Git and Gitaly service models that work across Self-Managed, GitLab Dedicated, and SaaS, with a clear view of which elements are common and which must differ between them. Maintain cloud-agnostic architecture and tooling decisions, avoiding designs that assume a single hyperscaler's primitives. Partner with the teams that own each deployment model so operational practices stay coherent rather than fragmenting into separate playbooks. Apply distributed systems fundamentals, including consistency, replication, and failure domains, to Gitaly's storage and replication model. Own elastic storage and compute strategy for Git repository data, including capacity planning, autoscaling, and consumption-based provisioning for GitLab's largest self-managed and SaaS customers. What you’ll bring Familiarity with GitLab's product and deployment models, and how Git and Gitaly support repository operations across self-managed, dedicated, and SaaS environments. Hands-on subject matter expertise in Git internals, including how the protocol, object model, and storage layer behave under load and at scale, not only familiarity with Git usage. Strong distributed systems fundamentals, including consistency, replication, failure handling, and horizontal scalability. Experience running production infrastructure across multiple deployment models, such as self-managed, dedicated or single-tenant, and multi-tenant SaaS, or a credible path from adjacent experience to it. Experience with elastic storage and compute, and consumption-based system design for variable, unpredictable load. People management experience, ideally leading site reliability engineering-style or platform operations teams. Direct experience with Gitaly, libgit2, JGit, or another Git implementation's internals is advantageous. Experience operating cloud-agnostic infrastructure across multiple hyperscalers or on-premises environments is advantageous. About the team The Git & Gitaly Operations team owns the Git infrastructure layer that powers GitLab and works at the intersection of Git internals, distributed systems, storage, and production operations. We expect the Git & Gitaly Operations team to go deep on one of GitLab's most critical platforms. The work requires technical depth, strong operational discipline, and the ability to solve complex reliability and scaling challenges in Git and Gitaly.
