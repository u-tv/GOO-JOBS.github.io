About Access Essentials Team The Access Essentials team at Okta owns the core control plane backend services, cloud configuration APIs, security and access frameworks, and unified administrative web applications. Our services power core authentication, telemetry pipelines, feature flagging, telephony, certificate management, and admin UI console experiences across Okta's enterprise footprint. We build scalable, highly available backend microservices and web interfaces that serve millions of users and administrators globally. Position Overview As a Senior SET on the Access Essentials team, you will take end-to-end ownership of the test strategy, test automation, and quality engineering for our backend services, cloud APIs, and web frontend applications. You will work closely with local engineering teams, architects, product managers, and cross-functional US partners to design, build, and optimize scalable, automated test solutions that keep release cadences reliable and low-risk for mission-critical cloud infrastructure and admin portal experiences. This role requires a deep understanding of backend microservices architecture, REST/gRPC APIs, web automation frameworks, distributed cloud systems (AWS), continuous integration/continuous deployment (CI/CD) pipelines, and enterprise security standards. Core Roles & Responsibilities Test Automation Framework Architecture Design & Scale: Build, maintain, and expand highly reusable test automation frameworks and performance test suites specifically tailored for backend microservices, REST/gRPC APIs, and modern web applications (Admin UI). Integrations & End-to-End Validation: Develop automated functional, integration, and E2E regression tests covering complex backend security workflows, cloud-config APIs, authentication protocols, and web UI console journeys. Flaky Test & CI/CD Stability: Lead guild initiatives to systematically triage and eliminate flaky UI and API tests, driving deterministic quality gates in build and deployment pipelines. Quality Engineering & Product Strategy Design Transparency & Shift-Left: Embed early into product ideation, technical architecture, and PRFAQ/spec reviews with Software Development Engineers (SDEs), Product Managers, and Architects to define quality criteria and perform technical risk analysis. Platform Ownership: Drive comprehensive test strategy, test case creation, execution, and effort estimations for backend services and web applications across the Access Essentials pillar. Technical Debt Reduction: Build automated infrastructure to facilitate service refactoring, API version migrations, and seamless database/service optimizations. CI/CD & DevOps Synergy Pipeline Integration: Maintain and optimize local CI/CD pipelines (leveraging tools like CircleCI, Spinnaker, or GitHub Actions) to enforce rapid, reliable release gates. Reliability Operations: Partner with Infrastructure and Site Reliability Engineering (SRE) teams to optimize mock service environments, manage test data, and maintain robust alert mechanisms for regression detection. Required Technical Skills & Qualifications Experience: 5+ years of experience in Software Engineering in Test (SET / SDET) roles, with strong focus on backend microservices, REST APIs, and Web UI application validation. Programming Proficiency: Strong coding skills in Java , Python , or JavaScript/TypeScript with a proven ability to write clean, scalable, and maintainable automation code. Web & API Testing Expertise: Hands-on expertise with web UI automation frameworks (Selenium, Cypress, Playwright) and API testing frameworks (Rest Assured, Karate, Postman, or gRPC tools). Backend & Cloud Systems Depth: Deep understanding of distributed systems architecture, cloud infrastructure (AWS), relational/NoSQL databases, and security protocols (OAuth, OIDC, SAML). Infrastructure & DevOps Familiarity: Direct experience working with CI/CD systems (CircleCI, Jenkins, Spinnaker), containerization (Docker, Kubernetes), and logging/observability platforms (Splunk, Datadog, Sentry). Education: B.Tech / B.E. in Computer Science, Information Technology, or a closely related technical field. Preferred Qualifications AI-Assisted Testing: Familiarity with using AI/LLM tools to accelerate test case generation, automation authoring, or defect triage Domain Expertise: Experience testing security software, enterprise Identity and Access Management (IAM) systems, MDMs or multi-tenant SaaS platforms. Web Front End Technology: Familiarity with modern frontend JavaScript frameworks (React) and enterprise Admin Console UX patterns.
