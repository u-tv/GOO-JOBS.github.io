EdgeQ Technologies Private Limited: Game UI Engineer

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: United States Game UI Engineer Job Title: Game UI Engineer Location: United States (Remote) Work Mode: 100% Remote Experience: 3–7 Years Salary Range: $85,000 – $140,000 per year (USD) Employment Type: Full-Time Job Category: Game Development / UI Engineering Job Summary We are seeking a talented and experienced Game UI Engineer to join our game development team in the United States. The ideal candidate will be responsible for designing, developing, implementing, and optimizing user interfaces for interactive games across multiple platforms. The candidate should have strong programming skills, experience with Unity or Unreal Engine, and expertise in creating responsive, intuitive, and visually appealing gaming interfaces that enhance player experience. This position offers a fully remote work opportunity for qualified candidates across the United States. Key Responsibilities Design, develop, and implement user interfaces for games and interactive applications. Build responsive game menus, HUDs, inventory systems, and navigation interfaces. Collaborate with game designers, artists, and developers to implement UI/UX requirements. Develop UI functionality using C++, C#, or relevant scripting languages. Implement animations, transitions, interactive elements, and visual effects. Optimize UI performance across desktop, mobile, console, and other gaming platforms. Integrate UI assets, graphics, fonts, and multimedia components. Ensure consistent UI functionality across different screen resolutions and devices. Debug and resolve UI-related performance and usability issues. Implement localization and accessibility features where required. Maintain reusable UI components and technical documentation. Participate in code reviews and Agile development processes. Required Skills & Qualifications 3–7 years of experience in Game UI Engineering or Game Development. Strong programming knowledge of C++, C#, or related languages. Hands-on experience with Unity or Unreal Engine. Experience developing game HUDs, menus, inventory systems, and interactive UI components. Strong understanding of UI/UX principles and responsive interface design. Experience with animation systems, UI transitions, and visual effects. Knowledge of game performance optimization and memory management. Familiarity with Git or other version control systems. Ability to collaborate with cross-functional and remote teams. Strong problem-solving and communication skills. Preferred Qualifications Bachelor's degree in Computer Science, Software Engineering, Game Development, or a related field. Experience with Unity UI Toolkit, uGUI, or Unreal UMG. Knowledge of Adobe Photoshop, Figma, or similar design tools. Experience with mobile game UI development. Familiarity with multiplayer game interfaces and real-time UI updates. Knowledge of localization, accessibility, and usability standards. Experience with console game development. Understanding of shader effects and UI rendering optimization. Salary & Benefits Annual Salary: $85,000 – $140,000 USD. Competitive compensation based on experience and technical expertise. 100% remote work opportunity. Flexible working arrangements. Health, dental, and vision insurance. Paid time off and holidays. Retirement savings benefits, where applicable. Professional development and training opportunities. Career growth opportunities. Work Location United States – Fully Remote Candidates from eligible locations across the United States are encouraged to apply. Must be legally authorized to work in the United States. Ability to collaborate with distributed teams across different time zones. How to Apply Interested candidates can submit their updated resume along with contact details, relevant Game UI Engineering experience, and portfolio showcasing previous game interface projects. Equal Opportunity Employer: We welcome qualified candidates from diverse professional backgrounds and encourage applications from eligible candidates across the United States.
