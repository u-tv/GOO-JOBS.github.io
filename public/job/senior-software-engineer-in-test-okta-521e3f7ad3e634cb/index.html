We are looking for a high-impact Senior Software Engineer in Test (Sr. SET) to join our QA Core Team. In this role, you will partner closely with Infrastructure, Release Engineering, and Development teams to drive high availability, build scalable test automation, and optimize CI/CD release pipelines. You will take ownership of release-based testing, system observability, and automation services to ensure that weekly software releases are delivered seamlessly and with high quality across mission-critical systems. Key ResponsibilitiesTest Automation & System Quality Design, implement, and maintain scalable test automation frameworks for both server- and client-side systems using Java, TestNG, JUnit, and Selenium. Develop and execute comprehensive end-to-end and system test plans to validate new software changes against existing customer deployment patterns. Set up and manage automated test configurations, lab environments, and containerized test setups using Docker. Perform release-based validation, ensuring full compatibility, high availability, and uptime across weekly deployment cycles. CI/CD Pipeline Maintenance & Optimization Troubleshoot, debug, and optimize CI/CD pipelines (Jenkins, GitHub Actions, CircleCI, Buildkite) to reduce test execution times and eliminate flaky builds. Manage and optimize Maven-based build structures, dependency management, and automated release workflows. Write operational automation scripts using Python, Bash, or Groovy to automate internal infrastructure and test maintenance tasks. Observability, Monitoring & Infrastructure Analyze application logs and system observability metrics using tools like Splunk, Sumologic, Kibana, or ELK to identify, isolate, and debug failures. Utilize SQL to query databases and validate complex, integrated backend scenarios. Provide occasional on-call support and debug assistance to partner teams in North America to ensure smooth global engineering alignment. Key Requirements Experience: 5 years of hands-on experience as a Quality Engineer or Software Engineer with a focus on SaaS products and release-based testing. Automation & Coding: 4+ years of Java-based test development (Selenium, TestNG, JUnit) and scripting proficiency in Python, Bash, or Groovy. CI/CD & DevOps: Demonstrated expertise in maintaining and debugging CI/CD pipelines, dependency management (Maven), and containerization platforms (Docker). Database & Data Querying: 4+ years of experience writing SQL queries to perform data verification and system integration testing. Observability: Strong experience leveraging monitoring tools (Splunk, Kibana, SumoLogic) to parse logs and trace test failures. Education: B.S. or M.S. in Computer Science, Computer Engineering, Software Engineering, or a closely related technical field. Preferred Qualifications Hands-on experience with cloud platforms (AWS, GCP, Azure) and Infrastructure as Code (Terraform, Ansible). Familiarity with Kubernetes, mobile testing platforms (e.g., Bitbar, Appium), or machine learning-driven test tools. Exposure to performance or security testing within CI pipelines.
