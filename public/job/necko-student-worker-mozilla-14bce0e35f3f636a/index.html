The Gecko networking team is looking for skilled developers to work on a first-class networking stack and improve web experiences for millions of Firefox users. The team is working on the core of the browser that moves the web. The fundamental network protocols and features like HTTP, QUIC, caching and DNS are our responsibility. We strive to provide a performant and secure browsing experience for the users. Furthermore we work on advanced web platform networking API like Fetch and WebTransport. About The Team and Role We strive to provide a performant and secure browsing experience for users and stable/easy to use Networking API's to our developers. What You’ll Get To Do Improve Firefox’s web browsing experience with a particular focus on the networking stack and network-related APIs, e.g., Fetch, WebTransport, etc. Design and implement new web platform features and networking protocols in collaboration with the web and internet standards community.
