Staff Software Engineer (Full Stack) - Imports Platform Company Description Okta is the leading independent provider of enterprise identity. The Okta Identity Cloud enables organizations to securely connect the right people to the right technologies at the right time. With over 6,500 pre-built integrations to applications and infrastructure providers, Okta customers can easily and securely use the best technologies for their business. Over 7,950 organizations, including 20th Century Fox, JetBlue, Nordstrom, Slack, Teach for America, and Twilio, trust Okta to help protect the identities of their workforces and customers. Position Description We are looking for an experienced Staff Software Engineer (Full Stack) to join our next-generation Imports Platform team. The Imports Platform team is leading a strategic initiative to modernize Okta's identity lifecycle management capabilities by architecting and migrating from a legacy monolithic system to a highly scalable, distributed microservices platform. This critical service orchestrates the importing, syncing, mapping, and provisioning of identities and access policies—users, groups, roles, entitlements—from external directory services including Active Directory, Office 365, and LDAP-based systems. As a Full Stack Staff Software Engineer , you will be a technical leader who independently owns end-to-end features and platform capabilities—spanning intuitive user interfaces, REST/GraphQL APIs, high-throughput asynchronous job engines, and microservice backends. You will drive technical strategy, make critical architectural decisions across the entire stack, and influence both your immediate team and cross-functional initiatives. You'll solve complex challenges ranging from building rich, responsive admin workflows to managing massive-scale batch processing, real-time synchronization, and identity resolution algorithms. This role requires strong technical leadership, strategic thinking, and the ability to balance short-term delivery with long-term platform health. You will mentor engineers across the full stack, partner closely with Product Management and UX on feature strategy, and help shape the future of Okta's Imports platform. This is a hybrid position requiring a blend of remote and in-office collaboration. Job Duties and Responsibilities Full-Stack Technical Leadership: Lead the architectural design and execution strategy across the full stack (Frontend, APIs, Microservices, Data Layers) for major platform initiatives. End-to-End Ownership: Independently own and deliver complex products end-to-end—from front-end admin configuration flows and wizard UIs to back-end event streams and database persistence. Monolith to Microservices Migration: Drive the migration strategy for full-stack features from legacy systems into modern, modular frontend applications and distributed microservices. API & System Design: Architect robust RESTful/GraphQL APIs and server-side components optimized for performance, security, and low-latency frontend interaction. Cross-Functional Collaboration: Partner closely with Product Managers, UX Designers, Architects, QA, and SRE to translate complex enterprise identity requirements into seamless user experiences and scalable technical designs. Code Quality & Standards: Conduct comprehensive code reviews across both frontend and backend codebases, enforcing high standards for performance, accessibility, security, testability, and maintainability. Operational Excellence: Troubleshoot complex production incidents spanning client-side applications, API gateways, and distributed backends; perform root cause analyses (RCAs) and drive systemic improvements. Mentorship & Growth: Mentor and guide senior and junior engineers across full-stack technologies, promoting software design best practices and fostering engineering velocity. Required Knowledge, Skills, and Abilities Experience: 7+ years of software development experience building highly reliable, mission-critical, enterprise-grade software at scale across both frontend and backend stacks. Backend Expertise: Deep expertise with Java and the Spring Boot framework for building distributed microservices, RESTful APIs, and scalable backend workflows. Frontend Expertise: Strong, hands-on experience with modern JavaScript/TypeScript frameworks ( React , Redux, or modern Web Components) and building complex, accessible enterprise web applications. Distributed Systems & Data: Experience with distributed job processing, event-driven architectures, relational databases ( MySQL ), caching layers ( Redis ), and message queues (e.g., Kafka, SQS). API Design: Proven track record designing, versioning, and maintaining clean RESTful or GraphQL APIs that power rich UI applications and enterprise integrations. Cloud Infrastructure: Solid understanding of cloud platforms (AWS/GCP), microservice architectures, CI/CD pipelines, and modern web deployment tools. Directory & Identity Services: Exposure to or understanding of Identity & Access Management concepts, directory services (Active Directory, LDAP, Azure AD), or SCIM/SAML/OAuth standards. Technical Leadership: Demonstrated ability to drive end-to-end architecture, break down complex initiatives into execution roadmaps, and mentor cross-functional team members. Nice to Haves Experience with frontend state management, micro-frontends, and design system integration (e.g., Okta Odyssey or similar UI libraries). Experience with server-side rendering, WebSockets, or real-time progress tracking for long-running batch operations. Experience with feature flag frameworks, A/B testing, and gradual rollout strategies for large-scale application migrations. Familiarity with UI automation testing tools (e.g., Cypress, Playwright, Jest) alongside backend TDD (JUnit/Mockito). Knowledge of user matching, correlation algorithms, and identity resolution at scale. Education and Training B.S. or M.S. in Computer Science, Software Engineering, or a related technical field (or equivalent practical experience).
