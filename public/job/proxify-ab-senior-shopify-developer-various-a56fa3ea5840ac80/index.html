Proxify AB: Senior Shopify Developer

🏢 Various 📍 Remote 💼 Full-time 💰 Not disclosed

Job Description

Headquarters: Sweden URL: http://career.proxify.io The Role: We are looking for a Senior Shopify Developer for one of our clients. You are a perfect candidate if you are growth-oriented, you love what you do, and you enjoy working on new ideas to develop exciting products and growth features. What we are looking for: 3+ years of dedicated experience architecting and scaling Shopify Plus stores, including advanced theme development using Shopify CLI, Liquid, and Online Store 2.0 JSON templates. 5+ years of core web development experience using modern JavaScript (ES6+), TypeScript, and React.js. Expertise in building responsive, accessible, and ultra-fast user interfaces without relying on excessive app code injections. Hands-on experience developing with Shopify Storefront API and Admin API (GraphQL and REST). Experience with headless e-commerce architectures using Hydrogen / Remix or Next.js is a significant advantage. Proven ability to build custom apps and extensions utilizing Shopify Functions (custom discount, shipping, and payment logic) and Checkout Extensibility. Mastery of site speed optimization (Core Web Vitals, asset minification, lazy loading) and A/B testing implementation (e.g., VWO, Optimizely) to continuously boost store conversion rates. Experience setting up reliable data pipelines between Shopify and external systems like ERPs (Netsuite, SAP), CRMs (HubSpot, Salesforce), and Subscription platforms (Recharge, Skio). Nice-to-have: Experience migrating legacy Shopify stores from vintage Liquid templates to Online Store 2.0 or Headless solutions. Experience building public or private Shopify Apps using Node.js / Remix / GraphQL. Familiarity with internationalization (Shopify Markets), multi-currency, and localization setups. Responsibilities: Architect and maintain pixel-perfect, mobile-first Shopify themes, utilizing modular Liquid components, custom sections, and metafields. Build custom Theme App Extensions and Shopify Functions to solve complex business logic (e.g., custom bundling, tiered pricing, subscription flows) while keeping the site lean and performant. Audit and refactor front-end code to maintain high Core Web Vitals scores, fast DOM rendering, and instant checkout transitions. Connect Shopify storefronts to third-party APIs, fulfillment partners, warehouse management systems (WMS), and marketing platforms using webhooks and GraphQL middleware. Maintain clean version control workflows using GitHub and Shopify CLI, enforcing automated code checks, staging previews, and safe production deployments.
