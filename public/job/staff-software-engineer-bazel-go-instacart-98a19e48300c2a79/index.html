We define and build the platforms, tools, and practices that enable Instacart engineers to ship high-quality software faster — from AI-powered code review to build infrastructure, developer onboarding, and local development environments. As a Staff Software Engineer on Developer Experience, you will lead two of the pillars that Instacart engineering is built on: Bazel (our build system) and Go (one of our core backend languages). You will own the technical direction for how thousands of daily builds run and how our Go services are structured, from remote build execution and caching to the frameworks, libraries, and patterns Go engineers use every day. This is a hands-on technical leadership role. You'll write code, set architectural direction, and partner across the org to move engineering-wide metrics on build performance, CI reliability, and developer velocity. Lead the technical direction for our Go platform, frameworks, standard libraries, service scaffolding, and patterns that Go engineers across Instacart depend on. Design and drive multi-quarter initiatives that measurably improve build times, CI reliability, and the local development loop for engineers working in Bazel and Go. Own the developer experience metrics for the systems you lead, define what &quot;good&quot; looks like, instrument it, and use the data to prioritize investment. Mentor engineers in the team and the broader engineering org; grow the community of Bazel and Go experts at Instacart. Represent the team in cross-org technical discussions on build, CI/CD, and backend platform direction.
