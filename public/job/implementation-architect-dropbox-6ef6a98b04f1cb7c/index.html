Implementation Architect

🏢 dropbox 📍 Remote - Canada: Select locations 💼 Full-time 💰 Not disclosed

Job Description

Role Description As an Implementation Architect at Dropbox, you will help customers successfully configure, implement, and launch Dropbox solutions across SMB, mid-market, and enterprise environments. You will own multiple concurrent implementations, guiding customers through configuration, integrations, identity setup, migrations, testing, enablement, go-live, and post-launch handoff. You will translate agreed solution designs into practical implementation plans, identify risks early, troubleshoot common technical issues, and keep customers and internal teams aligned through delivery. This role is designed for someone with hands-on experience implementing SaaS products who can independently deliver standard and moderately complex implementations using established approaches. You will work closely with Technical Architects, Customer Success, Support, Sales, and partners. You will also help improve implementation consistency by contributing lessons learned, reusable documentation, and practical feedback from customer deployments. Responsibilities Own several concurrent customer implementations from kickoff through configuration, testing, go-live, and post-launch handoff. Translate agreed solution designs and customer requirements into clear implementation plans, milestones, dependencies, and acceptance criteria. Support enterprise identity and access use cases including SSO/SAML, SCIM, identity provisioning, and permission configuration. Lead customer implementation workshops, technical working sessions, status meetings, enablement sessions, and implementation handoffs. Troubleshoot implementation issues using established tools, documentation, and escalation paths; identify when issues require support from Technical Architecture, Engineering, Security, Product, or Support. Document implementation decisions, configurations, testing results, risks, and handoff requirements clearly for customers and internal teams. Use approved AI and technical tools to accelerate implementation documentation, troubleshooting, scripting, testing, and knowledge capture while maintaining responsibility for output quality and accuracy.
